================================================================================
                        HOW TO GET STARTED
================================================================================

STEP 1: Deploy to Vercel (2 minutes)
  1. git push                    # Auto-deploys
  2. Or: vercel                  # Local deployment
  3. Or: Connect GitHub to Vercel

STEP 2: Initialize Database (1 minute)
  1. Visit: https://yoururl.com/init
  2. Click "Initialize CloudVault"
  3. Wait for 3 green checkmarks
  4. Click "Go to CloudVault"

STEP 3: Start Using! (30 seconds)
  1. Type in text editor
  2. Paste images with Ctrl+V
  3. Upload files by dragging
  4. Share URL with others
  5. All changes sync in real-time!

STEP 4: Install as App (Optional)
  1. Click browser menu (⋮)
  2. Select "Install app"
  3. Works offline!
